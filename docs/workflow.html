工作流

从采集到发布的完整自动化流程。

  1. 1

    定时触发

    每天 08:00（北京时间），云端的 GitHub Actions 自动启动（无需你的电脑开机）。

  2. 2

    采集

    并行读取 11 个信息源：官方博客、媒体、论文与社区。

  3. 3

    清洗

    按标题去重，并只保留最近 3 天发布的资讯。

  4. 4

    AI 筛选与摘要

    DeepSeek（deepseek-chat） 依据“兴趣画像”筛选、分组，写出中文摘要与“为什么重要”。

  5. 5

    推送

    生成飞书交互卡片，推送到你的飞书群（链接可直接点开）。

  6. 6

    存档与建站

    保存为 Markdown 存档，并重新生成这个网站（首页 + 历史）。
