# ☀️ AI 晨报 · 2026-10-23

## ☀️ 今日头条

1. **OpenAI 模型将登陆 Google Cloud 与 Gemini Model Garden**
   OpenAI 与 Google Cloud 达成合作，前沿模型和 Codex 工作流将进入 Gemini 的 Model Garden，并通过 Google Cloud Marketplace 提供。
   *为什么重要：两大竞争对手首次在云平台上互通，企业选型与多云部署格局将被重塑。*
1. **Anthropic 推出主动式 Agent「Claude Duet」**
   Claude Duet 会主动从已连接应用中发现问题并提醒用户，关键操作前先请求批准，从「你问我答」转向常驻式主动执行。
   *为什么重要：Agent 竞争从被动响应转向主动发现任务，是 Agent 产品形态的关键分水岭。*
1. **DeepSeek 完成 150 亿美元融资，宁德时代与腾讯领投**
   DeepSeek 最新一轮募资约 1000 亿元人民币，目标估值在谈判中两次上调，宁德时代和腾讯为最大投资方。
   *为什么重要：中国大模型最大规模融资之一，直接影响开源模型路线与算力投入节奏。*
1. **DeepSeek 与华为联合设计 AI 芯片，训练环节去英伟达化**
   华为工程师长期驻点 DeepSeek，把大模型训练的实际需求直接纳入芯片设计，试图在训练环节摆脱对英伟达的依赖。
   *为什么重要：模型厂商与芯片厂深度共创，可能改变国产算力供给与训练成本结构。*
1. **Anthropic 将 Agent Skills 捐给 Agentic AI Foundation**
   Anthropic 宣布把 Agent Skills 捐给中立基金会，承诺保持开放、社区驱动、厂商中立。
   *为什么重要：Skills 生态标准化提速，对 MCP 之后的 Agent 工具互操作影响深远。*
