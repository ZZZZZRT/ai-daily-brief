## 📄 研究与论文

- **终止滞后：编码 Agent 早早解出任务却迟迟不停**：论文刻画「termination lag」现象，即编码 Agent 在解出任务后仍继续多步操作，量化其代价。 [链接](https://arxiv.org/abs/2611.14960)
- **清理 Agent 历史反而有害：当环境仍保留错误时**：研究发现对工具型 Agent 的历史做压缩、修复或交接时，若环境中的错误状态未清除，清理反而损害表现。 [链接](https://arxiv.org/abs/2611.14654)
- **EvoX：把 Agent Harness 重新视为运行时策略**：EvoX 提出将 Agent 的执行框架当作可学习的运行时策略，以约束模型决策与实际执行之间的偏差。 [链接](https://arxiv.org/abs/2611.15006)
- **排行榜攻击：偏好式模型评测易被操纵**：论文指出 Arena 式偏好排名存在被操纵风险，对当前主流模型排行榜的可信度提出质疑。 [链接](https://arxiv.org/abs/2611.14769)
- **SynthCorp：为数据 Agent 定制基准生成平台**：SynthCorp 提供可定向生成数据 Agent 评测基准的平台，解决现有基准快速饱和的问题。 [链接](https://arxiv.org/abs/2611.14765)
- **Together Compiler：面向 AI 推理的持续编译**：针对模型发布频繁、架构多样化，提出持续编译方案以适配快速变化的推理负载。 [链接](https://arxiv.org/abs/2611.14681)
- **RSI-PDEbench：自改进 Agent 求解偏微分方程基准**：新基准用于评估自改进 Agent 在从采样数据中识别并求解 PDE 的能力。 [链接](https://arxiv.org/abs/2611.14949)
- **XYBench：关注问题背后的问题**：AllenAI 发布 XYBench，聚焦评测中「问题背后的真实意图」这一被忽视的维度。 [链接](https://huggingface.co/blog/allenai/xybench)
