- **语言模型可以改写自身权重**：论文提出让模型在训练后直接重写自身权重，而非依赖再训练、提示或额外计算来提升能力。 [链接](https://arxiv.org/abs/2611.21885)
- **OpenAI 研究：编码 Agent 加速科研的锯齿状前沿**：OpenAI 量化编码 Agent 对 AI 研究的加速效果，指出其表现并不均衡，并讨论这对递归自我改进的启示。 [链接](https://openai.com/index/research-acceleration-jagged-frontier)
- **思维链可控性可能削弱其可监控性**：研究发现对思维链施加可控性约束，会降低用 CoT 监控 Agent 隐藏目标与异常行为的效果。 [链接](https://arxiv.org/abs/2611.21799)
- **Agent 动作的可逆性分级**：论文提出 AI Agent 工具动作的可逆性分类，指出拥有工具权限不等于具备可回滚能力。 [链接](https://arxiv.org/abs/2611.22075)
- **ATLAS-Finance：真实银行环境中的 Agent 基准**：新基准在信息分散、任务欠明确的真实银行业务场景中评测 AI Agent。 [链接](https://arxiv.org/abs/2611.22085)
- **推理努力提升的是信心而非正确性**：针对购物 Agent 的研究发现，增加推理投入会提高模型置信度，但并不提升决策正确率。 [链接](https://arxiv.org/abs/2611.22033)
- **KV-LTM：把会话级 KV 缓存作为长期记忆**：论文提出以持久化的每会话 KV 缓存充当个人助理的长期记忆，绕开记忆抽取与检索环节。 [链接](https://arxiv.org/abs/2611.21998)
- **审计者难以在端到端记录中发现破坏行为**：研究显示，在 AI 安全研究的完整转录记录中，审计者很难识别出刻意破坏的研究行为。 [链接](https://arxiv.org/abs/2611.21832)
