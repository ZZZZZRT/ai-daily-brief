# ☀️ AI 晨报 · 2026-11-21

## ☀️ 今日头条

1. **Google 发布 Gemini 4 Neon，卡位性能与成本中间档**
   Gemini 4 系列新增 Neon 档位，定位介于攻坚型 Carbon 与轻量 Hydrogen 之间，100 万 token 上下文，输入 3 美元/百万 token、输出 15 美元/百万 token，缓存输入享 95% 折扣。
   *为什么重要：前沿模型开始按「任务难度分层定价」，直接影响 Agent 长链路任务的成本结构选型。*
1. **Gemini API 上线工具检索（Tool Retrieval）**
   Gemini API 新增工具检索能力，让模型在大量工具中动态检索并选择合适工具，而非一次性塞入全部工具定义。
   *为什么重要：工具规模一上去，工具选择就是 Agent 的主要瓶颈，这是 Agent 工程化的关键基础设施。*
1. **Anthropic 登陆纳斯达克，首日市值约 1.3 万亿美元**
   Anthropic 以每股 83 美元发行、募资约 800 亿美元，开盘涨 34% 后回落，收盘涨 17%，成为史上最大 IPO。
   *为什么重要：头部模型公司完成公开市场定价，将重塑整个 AI 行业的资本与人才竞争格局。*
1. **Claude Code 团队：约 90% 代码由 Claude 编写与评审**
   团队公开其验证回路实践，指出没有验证机制时最多并行一两个 agent，有了验证回路后可同时跑几十上百个。
   *为什么重要：这是当前 Agent 规模化落地最实用的经验：瓶颈不在生成，而在自动验证。*
1. **OpenAI 研究：编码 Agent 加速 AI 研究但能力参差**
   OpenAI 量化编码 agent 对 AI 研究的加速效果，指出性能在不同任务上极不均衡，并讨论这对递归自我改进的启示。
   *为什么重要：直接关系到「AI 加速 AI 研发」这一最受关注的能力边界判断。*
